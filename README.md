# Discboxd

*BR*

A ideia do Discboxd é ser um projeto inspirado no Letterboxd.   sua proposta é criar uma plataforma para conectar amantes de musica onde eles podem avaliar, descobrir e compartilhar experiências musicais.

O projeto tem como objetivo principal aprofundar meus conhecimentos em tecnologias como: Docker, aws, terraform, spring, react, CD/CD/, entre muitas outras coisas.

Pretendo usar o mínimo possível de IA durante o desenvolvimento.

*EN*

The idea behind Discboxd is to be a project inspired by Letterboxd. It's purpose is to create a plataform to connect music lovers, where they can rate, discover, and share musical experiences.

The project's main goal is to deepen my knowledge of technologies such as Docker, AWS, Terraform, Spring, React, CI/CD, among many other things.

I intend to use Ai as little as possible during development.
